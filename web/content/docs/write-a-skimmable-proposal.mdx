On the site, open a card and write in the box: the live skim line moves as you type, and everything below it is dimmed because nobody reads it. The questions are on the right.

<Steps>
<Step>

**Lead with the answers.** The title counts toward the window. Put the ask, the amount, the date and the fallback in the first sentences.

</Step>
<Step>

**Be specific.** A number, a date or a named action is FOUND. "A modest budget", "soon" and "as discussed" are MISSING.

</Step>
<Step>

**Read the result.** MISSING questions are named, and a rewrite moves them into the window. You have three attempts, and each holds the fee again.

</Step>
</Steps>

```js title="web/examples/read-proposal.mjs"
import { createClient } from 'genlayer-js';
import { studioDevnet } from 'genlayer-js/chains';

const SKIM = '0x9F09310beD488465b5cE7De55778E081beab9f27';
const chain = { ...studioDevnet, id: 61997, rpcUrls: { default: { http: ['https://studio-next.genlayer.com/api'] } } };

const client = createClient({ chain });
const [id = '1'] = process.argv.slice(2);
const p = JSON.parse(await client.readContract({ address: SKIM, functionName: 'get_proposal', args: [Number(id)] }));

if (!p.found) throw new Error('no such proposal');
console.log(`#${p.id} ${p.title}: ${p.state}, attempt ${p.attempts} of 3`);
for (const a of p.attempt_rows) console.log(`  attempt ${a.n}: ${a.labels.join(' ') || 'not read'} -> ${a.verdict || 'waiting'}`);
```

<Tab value="Python">

```python title="web/examples/read_proposal.py"


import json
import sys

from genlayer_py import create_account, create_client
from genlayer_py.chains import studio_devnet

SKIM = "0x9F09310beD488465b5cE7De55778E081beab9f27"
studio_devnet.rpc_urls = {"default": {"http": ["https://studio-next.genlayer.com/api"]}}

reader = create_account()
client = create_client(chain=studio_devnet, account=reader)
proposal_id = int(sys.argv[1] if len(sys.argv) > 1 else 1)
p = json.loads(client.read_contract(address=SKIM, function_name="get_proposal", args=[proposal_id], account=reader))

if not p["found"]:
    raise SystemExit("no such proposal")
print(json.dumps({
    "title": p["title"],
    "state": p["state"],
    "attempts": [{"n": a["n"], "labels": a["labels"], "verdict": a["verdict"]} for a in p["attempt_rows"]],
}, ensure_ascii=False))
```
