## The runtime header

The build spec names a GenVM v0.3 runner. Studio Next removed v0.3 and now requires v0.4: contracts deployed with v0.3 stop working, reads included, and new deployments must use the v0.4 runner. The contract therefore starts from `# v0.4.0` and the v0.4 runner hash above, checked with the network's own `gen_getContractSchemaForCode`. The contract source uses the same API names as before; only the first two lines differ.
