## open_card

open_card(name: str, questions: list[str], window_words: int, fee: int) -> int

Open a card with its questions, skim window (80 to 200 words) and fee (0 to 10 GEN). Returns the card id.

Refuses with:

- the fee is 0 to … GEN

## update_card

```python
update_card(card_id: int, questions: list[str], window_words: int) -> int
```

Owner only. New questions and window apply to later attempts; an open attempt keeps the rules it was cut under.

Refuses with:

- only the owner of the card may change it

## submit

```python
submit(card_id: int, title: str, text: str) -> int
```

Submit a proposal on a card and pay its fee. The first attempt is cut under the card's rules now. Returns the proposal id.

Refuses with:

- this author waits until a proposal on this card may be submitted again

## revise

```python
revise(proposal_id: int, text: str) -> int
```

A new attempt after a REWRITE, with the fee held again. The author only, a new text, at most 3 attempts in all. The attempt is cut under the card's rules as they are now. Returns the attempt number.

Refuses with:

- a proposal has at most … attempts
- an attempt is a new text
- only a proposal sent back for a rewrite can be revised
- only the author of the proposal may revise it

## judge

```python
judge(proposal_id: int) -> str
```

Anyone asks the validators to read the window of the current attempt. The window is cut here, in code, from the questions and window the attempt was cut under. Never moves money out of the contract.

Refuses with:

- this proposal has no attempt waiting to be read

## waive

```python
waive(proposal_id: int) -> int
```

The card's owner waives the rule for one proposal that has not opened or been shelved: it opens for voting, marked WAIVED on the page, and its fees go back to its author. Returns the amount credited.

Refuses with:

- only a proposal that has not opened or been shelved can be waived
- only the owner of the card may waive the rule

## withdraw

```python
withdraw() -> int
```

A top-level transfer of the caller's whole balance to the caller. The only call that pays.

Refuses with:

- nothing to withdraw
