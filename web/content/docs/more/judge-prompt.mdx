## What the judge never sees

The prompt carries the questions and the cut window and nothing else. The contract makes the cut in code, from the questions and window size the attempt was cut under, so a card edit never changes how an open attempt is read.

## What validators agree on

The leader and every validator ask the same prompt and answer one label per question. A validator agrees only when its own labels are the leader's: `mine["labels"] == theirs.get("labels")`, with no tolerance. The verdict is then code: nothing missing is SKIMMABLE, otherwise REWRITE, and SHELVED on the third attempt.
